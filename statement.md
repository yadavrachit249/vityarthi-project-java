# Student Attendance Manager

## Problem statement

Manual attendance tracking can be time-consuming and error-prone. This project provides a simple way to record and review student attendance digitally.

## Scope of the project

The project covers adding students, recording daily attendance, saving attendance data to a CSV file, and viewing attendance reports.

## Target users

- Teachers
- Tutors
- School or college administrators

## High-level features

- Add and list students
- Record students as present or absent for a selected date
- Save and load attendance data
- View attendance reports with present, absent, and attendance-rate summaries
